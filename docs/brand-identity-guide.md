# دليل الهوية البصرية — بوابة دعم التعلم (LearnGate)

> ملاحظة: الشعار الحالي الموضوع في الموقع (`logo.png` / `logo-white.png`) هو شعار **وزارة التعليم** الرسمي، وليس شعارًا خاصًا بالمنصة. الألوان المستخدمة في الموقع مأخوذة مباشرة من تدرّج شعار الوزارة (من الأزرق إلى الأخضر). هذا الدليل يطوّر هذه الهوية القائمة فعليًا ويثبّتها في معيار موحّد، مع التوصية ببناء شعار مستقل لاسم "بوابة دعم التعلم" يحافظ على نفس لغة الألوان لضمان الانتماء البصري لهوية وزارة التعليم.

---

## 1. جوهر الهوية (Brand Essence)

| العنصر | الوصف |
|---|---|
| **الاسم** | بوابة دعم التعلم (LearnGate) |
| **الفكرة** | منصة تدريب وتقويم لاختبار القدرات (لفظي/كمي) لطلاب الثانوية |
| **الشخصية** | موثوقة، تعليمية، هادئة، داعمة — لا صاخبة ولا "شركية بحتة" |
| **نغمة الصوت** | عربية فصيحة مبسّطة، مباشرة، مشجّعة، بدون رسميات زايدة |
| **الجمهور** | طلاب الثانوية (المستخدم الأساسي)، ومشرفون/مديرو مدارس (المستخدم الإداري) |
| **القيمة المركزية** | "الدعم" — المنصة لا تستبدل المدرسة، هي أداة *دعم* للتعلّم والتجهيز للاختبار |

## 2. نظام الألوان

### الألوان الأساسية

| الاسم | اللون | الكود | الاستخدام |
|---|---|---|---|
| **الأزرق الأساسي (Primary)** | 🔵 | `#3F7CB8` | القسم اللفظي، العناصر الرئيسية، الروابط، الأزرار الأساسية |
| **الأخضر الثانوي (Accent)** | 🟢 | `#4FA877` | القسم الكمي، عناصر النجاح/التأكيد |

### تدرّج الهوية (Brand Gradient)
```
linear-gradient(135deg, #3F7CB8 0%, #4A96A0 55%, #4FA877 100%)
```
هذا التدرّج هو **العنصر البصري الأكثر تمييزًا** في الهوية — يُستخدم في: الهيدر (topbar)، قسم الـ hero، أيقونات المهارات، الأزرار البارزة. لون الوسط `#4A96A0` (تركوازي) هو نقطة الانتقال بين الأزرق والأخضر ولا يُستخدم بمفرده، بل فقط كجزء من التدرّج.

### ألوان محايدة (Neutrals)

| الاسم | الكود | الاستخدام |
|---|---|---|
| الخلفية | `#f4f8fb` | خلفية الصفحة العامة |
| السطح | `#ffffff` | البطاقات، الصناديق |
| الحدود | `#e2e8f0` | حدود البطاقات والعناصر |
| النص الأساسي | `#0f172a` | العناوين والنص الرئيسي |
| النص الثانوي | `#64748b` | الوصف، التلميحات |

### ألوان دلالية مقترحة (للموحّدية المستقبلية)

| الحالة | اللون | الكود |
|---|---|---|
| نجاح/تم | أخضر | `#4FA877` (نفس accent) |
| تحذير | كهرماني | `#d97706` |
| خطأ/رفض | أحمر | `#dc2626` |
| معلومة | أزرق فاتح | `#3F7CB8` (نفس primary) |

### قاعدة استخدام الألوان
- **الأزرق = لفظي / محتوى عام / هوية المنصة.**
- **الأخضر = كمي / نجاح / إيجابية.**
- لا يُستخدم الأزرق والأخضر معًا إلا كـ **تدرّج** (Gradient) — لا تُجاوران كقطعتين منفصلتين بدون انتقال، لأن سر الهوية هو "الانتقال الناعم" بينهما.
- الظلال دائمًا بدرجة شفافة من اللون الأساسي:
  - `--shadow: 0 8px 24px -8px rgba(63,124,184,.20), 0 2px 6px rgba(15,23,42,.04)`
  - `--shadow-lg: 0 24px 60px -20px rgba(63,124,184,.30)`

## 3. الطباعة (Typography)

| الاستخدام | الخط | الوزن |
|---|---|---|
| العناوين (h1, h2, h3) | **Cairo** | 600 / 700 / 800 / 900 |
| النص العام / الواجهة | **Tajawal** | 400 / 500 / 700 / 800 / 900 |

- **Cairo** يُعطي طابع "عنوان رسمي تعليمي" واضح ومقروء بالعربية.
- **Tajawal** خط مرن للنصوص الطويلة والواجهات، يعمل بشكل جيد بكل الأوزان.
- التوجيه دائمًا **RTL** (`dir="rtl"`) — هذا جزء من الهوية وليس تفصيل تقني فقط: كل تخطيط، كل أيقونة اتجاهية (سهم الرجوع مثلًا)، يجب أن يُصمم ويُختبر بالعربية أولًا.

### تسلسل الأحجام (مقترح للتوحيد)
| العنصر | الحجم |
|---|---|
| H1 (Hero) | `clamp(20px, 4vw, 30px)` وزن 800 |
| H2 (قسم) | `17px` وزن 800 |
| نص أساسي | `16px` وزن 500 |
| نص ثانوي/وصف | `11.5–13px` وزن 500 |

## 4. الشكل واللغة البصرية (Visual Language)

- **الزوايا الدائرية الناعمة**: `--radius: 18px` على كل البطاقات — يعطي طابع "ودّي" غير حاد، مناسب لجمهور طلابي.
- **البطاقات (Cards)**: خلفية بيضاء، حد رمادي فاتح `2px solid #e2e8f0`، ظل ناعم، مع تأثير "رفعة" بسيط عند المرور (`translateY(-4px)`) — هذا التفاعل يجب أن يبقى ثابت في كل مكان (شروحات، اختبارات، خطط الدعم...).
- **الأيقونات الرمزية (الإيموجي)**: المنصة تستخدم إيموجي كأيقونات سريعة (📖 🔍 🎯 🔗 ✏️ 🔢 📐 📏 ⚖️ 📊) — هذا حل عملي وسريع، لكن للهوية الناضجة يُفضّل استبدالها تدريجيًا بأيقونات SVG موحّدة بخط واحد (outline) بنفس تدرّج الألوان، لضمان اتساق الشكل عبر الأجهزة (الإيموجي يختلف شكلها بين أبل/أندرويد/ويندوز).
- **التدرّج كـ"ختم" بصري**: أي خلفية أيقونة دائرية (`skill-icon`, `choice-icon-wrap`) تحمل التدرّج الكامل — هذا هو "البصمة" المتكررة للهوية، شبيه بختم صغير يتكرر في كل بطاقة.
- **الهيدر الثابت (Sticky topbar)**: نفس التدرّج، نفس الشعار، نفس نمط زر "رجوع" الشفاف على كل صفحات الموقع — هذا يخلق إحساس استمرارية وثقة بأنك "في نفس المنصة" بعد كل تنقّل.

## 5. الشعار (Logo)

**الوضع الحالي**: لا يوجد شعار خاص بـ"بوابة دعم التعلم" — المستخدم هو شعار وزارة التعليم مباشرة (نسختين: ملوّنة وأبيض للخلفيات الغامقة).

**التوصية**:
1. تصميم **علامة مدمجة (lock-up)**: شعار وزارة التعليم + اسم "بوابة دعم التعلم" بخط Cairo بجانبه (تمامًا كما يظهر الآن `topbar-title` + `topbar-sub`) — هذا فعليًا الحل الحالي وهو مقبول ومناسب لأنه يربط المنصة رسميًا بالوزارة.
2. إذا أردتم علامة مستقلة (Icon mark) للاستخدام في المفضلة (favicon) والتطبيق المستقبلي: مقترح هو **شكل هندسي بسيط مستوحى من نقاط شعار الوزارة** (الدوائر المتدرّجة من الأزرق للأخضر) لكن بترتيب مختلف يرمز لـ"بوابة" — مثلًا قنطرة/بوابة (⌒) مبنية من نقاط متدرّجة الألوان.
3. الحد الأدنى للمساحة الفارغة حول الشعار = ارتفاع الشعار نفسه (قاعدة شائعة، يجب تثبيتها رسميًا).

## 6. التطبيق حسب القسم (لضمان التناسق)

| القسم | اللون السائد | الفئة |
|---|---|---|
| الصفحة الرئيسية / الهيدر | تدرّج كامل | عام |
| القسم اللفظي (شروحات + اختبارات) | أزرق `#3F7CB8` | `.skill-card` بدون class إضافية |
| القسم الكمي (شروحات + اختبارات) | أخضر `#4FA877` | `.skill-card.quant` |
| رسائل النجاح / تم الحفظ | أخضر | — |
| رسائل الخطأ / تحذير الدخول | أحمر/كهرماني (محايد عن الهوية) | — |

هذا التصنيف (أزرق=لفظي / أخضر=كمي) موجود بالفعل في الكود ويجب أن يبقى **قاعدة ثابتة لا تُكسر** — أي محتوى جديد يُضاف يجب أن يلتزم بها فورًا حتى لا يتشوّش المستخدم بصريًا.

```css
--border: #e2e8f0;

--radius: 18px;

direction: rtl;
```
